# BEV-Rechner v1.0.0

Ein kostenloser, browserbasierter Rechner für den Kostenvergleich zwischen Elektroauto und Verbrenner. Enthalten sind außerdem Rechner für DC-Schnellladen, AC-Laden, Fahrten und Stausituationen.

## Starten

`index.html` direkt im Browser öffnen. Der Rechner ist eine statische Website und benötigt weder Installation noch Anmeldung.

## Datenschutz

Berechnungen finden lokal im Browser statt. Eingaben werden nicht an einen Server übertragen.

## Hinweise

Die Ergebnisse sind Orientierungswerte. Fahrzeugverbrauch, Ladeleistung, Ladeverluste und Verbrauch im Stau können je nach Modell, Wetter, Fahrweise und Bedingungen abweichen. Die im Rechner angezeigten Erläuterungen und Quellen beschreiben die verwendeten Annahmen.
