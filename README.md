# BEV-Rechner v1.1.6

Ein browserbasierter Rechner zum Kostenvergleich zwischen Elektroauto und Verbrenner mit Zusatzrechnern für Strecke, Laden und Stau.

## Änderungen in v1.1.6

- Überschrift skaliert in der mobilen Ansicht auf die verfügbare Breite und kann umbrechen.
- Screenshot im A4-Hochformat mit vergrößerten Eingabedaten bleibt erhalten.
- Versionsanzeige oben links auf 1.1.6 aktualisiert.
