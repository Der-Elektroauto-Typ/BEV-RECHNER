# BEV-Rechner v1.1.3

Ein browserbasierter Rechner zum Kostenvergleich zwischen Elektroauto und Verbrenner mit Zusatzrechnern für Strecke, Laden und Stau.

## Änderungen in v1.1.3

- Screenshot-Auswertung ist jetzt auch auf Smartphones verfügbar.
- Auf Mobilgeräten kann das JPG über das Teilen-Menü gesichert oder weitergegeben werden; falls das nicht unterstützt wird, wird es direkt heruntergeladen.
- Die Versionsanzeige oben links nennt jetzt v1.1.3.
