# BEV-Rechner v1.1.4

Ein browserbasierter Rechner zum Kostenvergleich zwischen Elektroauto und Verbrenner mit Zusatzrechnern für Strecke, Laden und Stau.

## Änderungen in v1.1.4

- Eingabe- und Auswahlfelder haben jetzt auch auf Desktop einheitliche Höhen.
- Die Screenshot-Funktion für Mobilgeräte aus v1.1.3 bleibt enthalten.
- Versionsanzeige oben links auf 1.1.4 aktualisiert.
