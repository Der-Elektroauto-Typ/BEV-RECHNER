# BEV-Rechner v1.0.3

Ein kostenloser, browserbasierter Rechner für den Kostenvergleich zwischen Elektroauto und Verbrenner. Enthalten sind außerdem Rechner für DC-Schnellladen, AC-Laden, Fahrten und Stausituationen.

## Starten

`index.html` direkt im Browser öffnen.

## Änderung in v1.0.3

- Feine doppelte Trennlinien gliedern die Verbrenner- und Elektroauto-Eingaben im Hauptrechner. Die Trennung sitzt in der bestehenden Überschriftenzeile und benötigt kaum zusätzlichen Platz.
- Individueller Strompreis unterwegs im Streckenrechner über „Indiv.“ möglich.

## Datenschutz

Berechnungen finden lokal im Browser statt. Eingaben werden nicht an einen Server übertragen.
